# 데이터 처리 및 보관 정책

이 문서는 구현과 운영을 위한 정책이다. 실제 서비스의 개인정보 안내와 동의 문구는 운영 주체, 연락처, 제공자 및 이용 지역을 확정하고 검토한 후 게시한다. 이 문서만으로 법적 요구 충족을 주장하지 않는다.

## 처리하는 데이터와 목적

개인 계정 도입 후 저장 대상은 검증된 이메일, 표시 이름, 인증 제공자 issuer/subject, 초대·프로젝트 역할, 세션과 MCP 토큰의 해시 및 만료 정보다. 비밀번호와 로그인 제공자의 장기 액세스 토큰은 보관하지 않는다. 프로젝트 제목·카드·담당자·설명과 수정 주체는 협업을 위해 저장한다. 사용자는 프로젝트에 개인 민감정보와 인증 비밀을 기록하지 않는다.

보안 로그는 이상 접속과 권한 변경 추적을 위해 최소 메타데이터만 기록한다. 브라우저의 필수 세션 쿠키 외에 광고·행동 추적 쿠키를 사용하지 않는다. 현재 localStorage의 표시 이름과 마지막 프로젝트 ID는 사용 편의를 위해 그 브라우저에 남으며 로그아웃·계정 변경 때 정리하는 것을 공식 계정 전환의 요구사항으로 둔다.

## 보관과 삭제

프로젝트 데이터는 프로젝트 관리자가 삭제할 때까지 보관한다. 활성 세션은 절대 만료 12시간과 유휴 만료 30분을 목표로 하며, 만료된 세션 원문은 보관하지 않는다. MCP 토큰은 최대 30일 유효기간을 적용하고 철회 즉시 사용을 차단한다. 초대는 7일 뒤 만료한다. 보안 감사 로그는 90일, 백업은 30일 보관 후 폐기한다.

삭제 요청은 운영자가 신원을 확인한 뒤 30일 이내 처리한다. 다른 사용자가 계속 사용하는 프로젝트의 감사 이력은 필요한 식별자를 최소화하고, 사용자 삭제와 프로젝트 삭제를 구분한다. 삭제된 데이터가 백업에 남는 기간은 최대 30일이며 사고 복구 외의 목적으로 사용하지 않는다. 백업을 복구하면 이후 발생한 삭제·철회 요청을 다시 적용한다.

## 외부 처리와 운영 책임

Tailscale은 외부 HTTPS 접속 경로를 제공하며 호스트의 앱 서버가 응답을 처리한다. 로그인 제공자는 선택한 계정 인증을 처리한다. AI 데이터 전송은 사용자가 선택한 AI 클라이언트·모델 제공자에 따라 달라지며 프로젝트별 승인이 필요하다.

공식 공개 전에 운영 주체와 개인정보·보안 문의 경로, 실제 로그인·AI·백업 제공자, 저장 지역과 각 제공자의 처리 조건을 확인하고 이용자에게 알린다. 이 정보가 확정되지 않으면 공식 서비스 출시를 차단한다.
