# DDD Builder 공식 운영 보안 설계

상태: 사용자가 공식 운영에 적합한 보안과 정책 구현을 요청했다. 초대 기반 OIDC 로그인을 기본안으로 제안했고 사용자 유형과 로그인 선호 답변을 기다린다. 현재 Funnel 공개 앱의 데이터와 접속은 인증 전환 설정이 준비될 때까지 보존한다.

## 목표와 범위

OWASP ASVS 5.0의 인증·세션·접근 제어·보안 로그 항목을 검증 기준으로 삼는다. 인증 또는 무결점 보안을 주장하지 않는다. 먼저 현재 서버의 방어와 운영 정책을 구현하고, 개인별 인증과 프로젝트 권한 및 MCP 토큰을 추가한다. 단일 서버와 SQLite는 유지한다. 고가용성·대규모 멀티테넌트·공개 회원가입·결제는 범위 밖이다.

## 선택한 구조와 대안

기존 계정 OIDC 인증을 추천한다. 서버가 비밀번호를 보관하지 않고 계정 제공자의 MFA를 활용할 수 있다. 직접 비밀번호 인증은 복구·MFA·메일 발송 책임이 추가되므로 별도 요구가 있을 때만 채택한다. 기업 SSO는 같은 OIDC 인터페이스로 제공자와 조직 정책을 설정한다.

기본 접근 정책은 초대 기반이다. 이메일 검증만으로 누구나 가입하지 않는다. 최초 관리자 이메일은 서버 설정으로 지정하고, 로그인 제공자의 검증된 이메일 및 issuer/subject로 본인을 식별한다. OIDC state·nonce·PKCE를 매 로그인마다 만들고 유효기간 5분의 브라우저 쿠키에 연결한다. 등록된 HTTPS callback 주소만 사용한다.

## 접근 제어와 MCP

프로젝트마다 관리자·편집자·조회자 권한을 서버에서 검사한다. 목록·조회·SSE·presence·검색·내보내기에서도 허용된 프로젝트의 데이터만 보낸다. 권한 철회 즉시 세션과 스트림을 재검증한다. 사용자 이름은 본인 확인 수단으로 쓰지 않는다.

MCP는 개인이 발급하는 프로젝트 범위 토큰으로 인증한다. 읽기 또는 편집 범위, 최대 30일 유효기간, 즉시 철회, 발급 시 한 번 표시를 적용한다. DB에는 토큰 원문을 저장하지 않는다. 사용자는 본인의 현재 프로젝트 권한보다 강한 토큰을 발급할 수 없으며, 권한 철회 후 기존 토큰도 차단된다. 기존 공유 코드와 DDD_READ_ONLY만으로 공식 권한을 부여하지 않는다.

## 기본 방어

CSP로 자체 스크립트만 허용하고 iframe·외부 객체·base 변경을 차단한다. 기존 화면의 style 속성은 허용한다. HTTPS 요청에 HSTS를 적용하고 HTTP localhost 개발은 유지한다. 쿠키는 HttpOnly·SameSite·HTTPS Secure를 적용한다.

로그인·API 요청을 제한하며 제한 키와 버킷 수에 상한을 둔다. 프록시 전달 헤더는 기본적으로 신뢰하지 않는다. 연결 상대의 IP를 우선 사용하고, 설정으로 지정한 신뢰 프록시에서만 검증된 IP를 사용한다. 로그인 시도 제한은 Retry-After와 429로 응답한다. 활성 세션·전체 SSE·세션별 SSE에 상한을 적용하고 거절 시 기존 연결을 유지한다.

Funnel 운영의 호스트 3210 포트는 127.0.0.1에만 공개한다. 컨테이너는 비특권 사용자, 읽기 전용 앱 파일 시스템, 메모리·CPU·프로세스 제한을 사용한다. 데이터 볼륨을 Git과 이미지에서 제외한다.

## 운영 정책

접속 성공·실패, 권한 변경, 토큰 발급·철회, 데이터 변경·내보내기를 기록한다. 로그에 접속 코드·쿠키·토큰·프로젝트 본문을 기록하지 않는다. 조회 권한과 보관 기간을 명시한다. 운영자 지정, 암호화 백업과 복원 시험, 보안 업데이트 주기, 사고 대응 및 정보 삭제 절차를 제공한다. AI로 전달하는 프로젝트 데이터는 승인된 제공자·범위로 제한한다.

## 배포와 검증

기존 앱은 제자리에서 변경하지 않고 별도 worktree에서 개발한다. 실제 프로젝트는 변경하지 않는 테스트와 별도 DB·Docker 볼륨으로 검사한다. 인증 전환은 관리자 로그인·데이터 이전·롤백을 확인한 뒤에만 한다. 공식 운영 모드에서는 공유 코드와 미완성 인증 설정으로 기동하지 못하도록 한다. 실제 OIDC 제공자 등록과 MFA·운영자·보안 연락처·백업 대상 설정이 완료되지 않으면 출시 준비 상태로 표시한다.

요청 제한·보안 헤더·연결 제한, 세션 만료·철회, 역할별 API와 SSE 격리, MCP 범위·만료·철회, OIDC 서명·issuer·audience·state·nonce·PKCE 오류, 기존 데이터 보존 및 복원, 브라우저 화면을 자동 검증한다.
